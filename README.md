# JLE ENGINE

Made by Jia Hao Zhao, Luying Bao Cheng and Erik Argemí Chinchilla.



https://github.com/ErikArgemi/JLE-Engine

This is a game engine made for our Videogame engine course for 3D videogames.



## Controls:

#### Camera Controls:

*(MOUSE MUST BE HOVERING ON THE SCENE SCREEN)*

* Keep \[Right Mouse Button] pressed to enable FPS-like movement:

  * \[WASD]: forward, left, down, and right movement.
  * Move \[Mouse] to look around.
  * \[QE]: to move up and down respectively.
  * \[Shift]: speed boost.
* \[Scroll]: zoom in and out.
* \[F]: focus on selected object.
* \[Alt] + \[Left Mouse Button]: to orbit around the selected object.

#### Other Controls:

* \[X]: Quit



## Extras:

* Added dragbars to the inspector window that transforms selected objects.
* Added Camera sliders in the Configuration Window that allows adjusting of movement speed and sensitivity.
